# AI CampusPulse — Student Engagement Platform

AI CampusPulse is a comprehensive, data-driven student engagement platform designed to bridge the gap between students and campus administration.

The platform features real-time campus polls, career readiness evaluations, timed academic assessments, event registration, and an interactive admin dashboard.

Built and fully integrated end-to-end by a four-person team over two iterative development cycles.

## 🛠️ Tech Stack & Architecture

AI CampusPulse is engineered using a modern, scalable full-stack architecture.

| Layer                                 | Technology                                                                     |
| ------------------------------------- | ------------------------------------------------------------------------------ |
| **Frontend**                          | Next.js 14, React, Tailwind CSS                                                |
| **Backend**                           | NestJS, TypeScript, REST APIs                                                  |
| **Database**                          | PostgreSQL 16                                                                  |
| **Infrastructure & Containerization** | Docker, Docker Compose                                                         |
| **Authentication & Security**         | JWT (JSON Web Tokens), Parameterized Queries, Role-Based Access Control (RBAC) |

## ✨ Key Features

### 🎓 For Students

* **Interactive Dashboard:** View personal engagement scores, recent test performances, active polls, and upcoming events.
* **Campus Polls:** Participate in active campus voting with instant result updates and duplicate-vote prevention.
* **Academic Assessments:** Take timed quizzes featuring category-based scoring and question flagging capabilities.
* **Career Readiness Quizzes:** Complete career evaluations and receive dynamic improvement feedback generated by a shared scoring engine.
* **Event Management:** Browse upcoming campus activities and register with real-time status tracking.

### 🛡️ For Administrators

* **Analytics Panel:** Monitor campus-wide participation metrics, overall assessment performances, and real-time poll distributions.
* **Content Creation:** Instantly create and publish new polls and campus events visible to all students immediately.
* **Data Insights:** View aggregate career readiness and academic strengths across the student body.

## 🚀 Local Setup & Installation

To run this repository locally, make sure you have the following installed:

* [Docker](https://www.docker.com/)
* Node.js v18 or later
* npm

### 1. Database & API Setup

Navigate to the API directory:

```bash
cd campuspulse-api
```

Start the PostgreSQL 16 database using Docker Compose:

```bash
docker compose up -d
```

Create your local environment file:

```bash
cp .env.example .env
```

Open `.env` and configure the required environment variables, including a custom `JWT_SECRET`.

> **Security:** Never commit your `.env` file, JWT secrets, database passwords, or other sensitive credentials to the repository.

Install the backend dependencies:

```bash
npm install
```

Seed the database with sample data:

```bash
npm run seed
```

The seed process loads the database schema, test questions, demo students, and active polls.

Start the development server:

```bash
npm run start:dev
```

The API runs on:

```text
http://localhost:4000
```

---

### 2. Frontend Setup

Navigate to the frontend directory:

```bash
cd campuspulse-web
```

Install the frontend dependencies:

```bash
npm install
```

Create the local environment file:

```bash
cp .env.example .env.local
```

The environment configuration is pre-configured to target the local backend at:

```text
http://localhost:4000
```

Start the Next.js development server:

```bash
npm run dev
```

The frontend runs on:

```text
http://localhost:3000
```

For local development, create your environment files from the provided examples:

```text

```

* Database credentials
* API keys
